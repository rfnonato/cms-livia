# Documentação do ContentMinimal CMS

Esta pasta contém toda a documentação relacionada ao projeto ContentMinimal CMS.

## Arquivos de Documentação

- [**contentminimal-documentation.md**](./contentminimal-documentation.md): Documentação principal do projeto com informações detalhadas sobre arquitetura, componentes, páginas e fluxos de trabalho.
- [**ui-components.md**](./ui-components.md): Guia detalhado dos componentes de interface do usuário disponíveis no sistema, incluindo exemplos de uso.
- [**user-guide.md**](./user-guide.md): Manual do usuário com instruções passo a passo sobre como utilizar as funcionalidades do CMS.

## Como Usar a Documentação

A documentação foi projetada para servir como referência tanto para desenvolvedores quanto para usuários do sistema:

- **Para desenvolvedores**: Encontre informações sobre a arquitetura, estrutura do projeto, convenções de código e como estender o sistema.
- **Para usuários**: Aprenda sobre os fluxos de trabalho principais, como criar conteúdo e configurar o sistema.

## Atualizando a Documentação

Ao fazer alterações significativas no projeto, por favor, atualize a documentação correspondente para mantê-la sincronizada com o código-fonte atual.

## Convenções

- Use Markdown para toda a documentação
- Mantenha uma estrutura consistente nos documentos
- Inclua exemplos de código quando relevante
- Use títulos e subtítulos para organizar o conteúdo
- Inclua links para recursos relacionados
