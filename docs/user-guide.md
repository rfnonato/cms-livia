## Primeiros Passos

### Acessando o CMS

1. Abra seu navegador e acesse o URL do seu site seguido por `/admin` (ex: `https://seusite.com/admin`)
2. Faça login usando suas credenciais
3. Você será redirecionado para o painel de controle (Dashboard)

### Visão Geral do Dashboard

O Dashboard fornece uma visão geral do seu conteúdo e atividades recentes, mostrando:

- Total de posts
- Quantidade de arquivos de mídia
- Número de assinantes
- Páginas publicadas
- Gráfico de atividades recentes
- Posts recentes

## Navegação no Painel de Controle

O menu lateral (Sidebar) é sua principal ferramenta de navegação, contendo links para todas as seções do CMS:

- **Dashboard**: Visão geral e estatísticas
- **Posts**: Gerenciamento de artigos e blog posts
- **Media**: Biblioteca de arquivos (imagens, vídeos, áudios)
- **Newsletter**: Gerenciamento de campanhas de email
- **Pages**: Páginas estáticas do site
- **Settings**: Configurações do sistema

Você pode recolher a barra lateral usando o botão no canto superior direito para ter mais espaço de trabalho.

## Gerenciando Posts

### Visualizando Posts

Na seção Posts, você encontrará uma lista de todos os seus artigos. Você pode:

- Filtrar por status (Todos, Publicados, Rascunho, Agendados)
- Pesquisar posts pelo título
- Ver informações como status, data e visualizações
- Acessar ações para cada post (editar, visualizar, excluir)

### Criando Novos Posts

Para criar um novo post:

1. Clique no botão "New Post" no canto superior direito
2. Adicione um título ao seu post
3. Escreva seu conteúdo usando o editor de texto
4. Use os botões da barra de formatação para estilizar seu texto, adicionar links, listas e imagens
5. Adicione um trecho (excerpt) para resumir seu post

### Configurações de SEO

Para otimizar seu post para mecanismos de busca:

1. Preencha o campo "SEO Title" (geralmente similar ao título do post, mas otimizado para SEO)
2. Escreva uma "Meta Description" atraente e informativa (até 160 caracteres)
3. Adicione palavras-chave relevantes, separadas por vírgulas

### Publicação e Agendamento

Para publicar ou agendar seu post:

1. No painel lateral direito, selecione o status desejado (Rascunho, Publicado, Agendado)
2. Escolha as opções de visibilidade (Público, Privado, Protegido por senha)
3. Se agendar, selecione a data de publicação
4. Clique em "Publish" para publicar imediatamente ou "Save as Draft" para salvar como rascunho

### Categorias e Tags

Para organizar seu conteúdo:

1. Selecione uma categoria para o post
2. Adicione tags relevantes, separadas por vírgulas
3. Se necessário, crie novas categorias nas configurações

## Trabalhando com Mídia

### Biblioteca de Mídia

A seção Media permite gerenciar todos os seus arquivos:

- Filtrar por tipo (Todos, Imagens, Vídeos, Áudios)
- Pesquisar arquivos pelo título
- Visualizar detalhes como tipo, fonte, data e tamanho
- Realizar ações como visualizar, baixar, copiar link e excluir

### Adicionando Mídia

Para adicionar novos arquivos:

1. Clique no botão "Add Media" no canto superior direito
2. Escolha entre:
   - **Upload File**: Arraste e solte ou selecione um arquivo do seu computador
   - **External Link**: Adicione links para conteúdo externo (YouTube, Spotify, etc.)
3. Preencha o título e informações do arquivo
4. Clique em "Add Media" para confirmar

### Usando Mídia em Posts

Para inserir mídia em seus posts:

1. No editor de posts, clique no botão de imagem na barra de formatação
2. Selecione um arquivo da biblioteca ou faça upload de um novo
3. Ajuste as configurações (tamanho, alinhamento, etc.)
4. Insira no conteúdo

## Configurando Newsletters

### Gerenciando Assinantes

Na seção Newsletter, você pode:

- Ver lista completa de assinantes
- Adicionar novos assinantes manualmente
- Importar listas de assinantes
- Organizar assinantes em grupos
- Gerenciar cancelamentos de inscrição

### Criando Campanhas

Para criar uma nova campanha de email:

1. Clique em "New Campaign"
2. Escolha um modelo ou comece do zero
3. Preencha o assunto e conteúdo do email
4. Personalize o design usando o editor visual
5. Selecione o grupo de destinatários
6. Agende ou envie imediatamente

### Analisando Resultados

Após enviar sua campanha, você pode:

- Ver taxas de abertura e cliques
- Acompanhar conversões
- Identificar cancelamentos de inscrição
- Exportar relatórios

## Criando e Editando Páginas

### Gerenciando Páginas

Na seção Pages, você pode:

- Ver todas as páginas do site
- Filtrar por status e tipo
- Editar páginas existentes
- Criar novas páginas

### Usando o Construtor de Páginas

O PageBuilder oferece uma interface intuitiva:

1. Adicione e organize elementos arrastáveis na página
2. Configure cada elemento individualmente
3. Visualize como ficará em diferentes tamanhos de tela
4. Configure opções de SEO para a página
5. Salve como rascunho ou publique

### Tipos de Elementos

O construtor de páginas oferece vários elementos:

- **Texto**: Blocos de texto formatáveis
- **Imagem**: Fotos e gráficos
- **Vídeo**: Vídeos hospedados ou incorporados
- **Galeria**: Conjuntos de imagens
- **Botão**: Botões de chamada à ação
- **Formulário**: Formulários personalizáveis
- **HTML**: Código HTML personalizado

## Configurações do Sistema

### Configurações Gerais

Na aba General:

- **Site Name**: Nome do seu site
- **Site URL**: URL principal do site
- **Site Description**: Descrição breve do seu site
- **Timezone**: Fuso horário para publicações e agendamentos
- **Language**: Idioma principal do site
- **Maintenance Mode**: Ativar/desativar modo de manutenção

### Perfil de Usuário

Na aba Profile:

- **Personal Information**: Nome, email, bio
- **Avatar**: Imagem de perfil
- **Password**: Alteração de senha
- **Preferences**: Configurações de interface

### Aparência

Na aba Appearance:

- **Theme**: Seleção de tema visual
- **Colors**: Cores primárias e secundárias
- **Typography**: Fontes e tamanhos
- **Layout**: Opções de layout do site

### Redes Sociais

Na aba Social Media:

- **Profiles**: Links para seus perfis sociais
- **Sharing**: Configurações de compartilhamento
- **Auto-posting**: Automatização de postagens nas redes

### Notificações

Na aba Notifications:

- **Email Alerts**: Configuração de alertas por email
- **Mobile Notifications**: Alertas para dispositivos móveis
- **Activity Reports**: Relatórios periódicos

### Segurança

Na aba Security:

- **Login Security**: Configurações de login
- **Two-Factor Authentication**: Autenticação de dois fatores
- **API Keys**: Gerenciamento de chaves API
- **Session Management**: Controle de sessões ativas

## Dicas e Melhores Práticas

### Otimização de SEO

- Use títulos descritivos e relevantes
- Escreva meta descrições atraentes
- Inclua palavras-chave estratégicas sem exageros
- Otimize imagens com textos alternativos

### Criação de Conteúdo

- Mantenha uma regularidade na publicação
- Use imagens de alta qualidade
- Divida textos longos em seções com subtítulos
- Use a formatação para destacar informações importantes

### Performance

- Otimize o tamanho das imagens antes de fazer upload
- Evite vídeos muito grandes hospedados diretamente
- Limpe regularmente mídias não utilizadas
- Monitore as estatísticas de carregamento

### Segurança

- Altere sua senha regularmente
- Ative a autenticação de dois fatores
- Faça backup regular do conteúdo
- Mantenha o sistema atualizado
